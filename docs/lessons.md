# Уроки

## 2026-09-14 — файлы конфига должны быть читаемы пользователем контейнера

Мост упал на старте с `[Errno 13] Permission denied: '/app/config.local.yaml'`.
Причина: файл создавался под `umask 077` как `600 root:root`, а контейнер
работает от UID 10001 — монтирование `:ro` прав не добавляет.

Правило для любого файла, который монтируется внутрь контейнера:
`chown 10001:10001` + `chmod 400` (или `444`, если секретов нет). Режим 600
оставлять только тем файлам, которые читает docker compose на хосте
(`.env*` с токенами).

Проверять до запуска приложения одной командой:
`docker run --rm --user 10001:10001 -v <файл>:/app/x:ro alpine sh -c 'head -c 1 /app/x'`.

## 2026-09-12 — лимит авторизации MAX

Ошибка `limit.violate` при запросе SMS-кода нельзя обрабатывать как обычный
сетевой обрыв: повторные попытки каждые 5 секунд сами продлевают ограничение.
Для авторизации нужен остановленный режим до ручного повторного запуска после
снятия лимита.
